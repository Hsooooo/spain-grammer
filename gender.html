7명사의 성과 수

성 (Género)

남성 el / un
어미 -oel libro, chico
어미 -or / -ónel color, camión
어미 -mael problema, tema
요일·월·언어el lunes, español
여성 la / una
어미 -ala casa, chica
어미 -ción / -siónla nación, lección
어미 -dad / -tadla ciudad, libertad
어미 -ez / -umbrela niñez, costumbre
예외 — 남성인데 -a 어미
el problema, el tema, el día, el mapa
예외 — 여성인데 -o 어미
la mano, la foto, la moto, la radio
⚠️ 주의할 예외
성에 따라 뜻이 달라짐: el capital (자본) / la capital (수도)
el + 여성명사(a- 시작): el agua, el águila (발음 편의상)

수 (Número) · 형용사 일치

복수형 규칙
모음 끝 +scasa → casas
자음 끝 +esciudad → ciudades
-z → -cesluz → luces
사람 명사 성 변화
-o → -aamigo → amiga
-or → -oraprofesor → profesora
-ante/-ente/-istael/la estudiante, artista
형용사 성·수 일치
-o / -a 형용사
chico alto / chica alta
chicos altos / chicas altas
-e / 자음 형용사
chico interesante / chica interesante
남녀 형태 동일, 복수만 +s / -es
📝 관사도 명사 성에 맞춰야 해요 — el / un (남성), la / una (여성)
혼합 그룹은 남성 복수로 통일: amigos = 남자 친구들 또는 남녀 혼합 친구들
